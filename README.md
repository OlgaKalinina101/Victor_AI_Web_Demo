## Что и где запускается (самое простое объяснение)

- **Frontend (этот проект)**: поднимается на `http://localhost:5173`
- **Backend (FastAPI)**: поднимается на `http://127.0.0.1:8000`

Frontend будет отправлять запросы в backend.
Если backend запущен на этом же ноутбуке на порту `8000`, то **ничего настраивать не нужно** — всё уже настроено по умолчанию.

## Быстрый старт (локально на одном ноутбуке)

### 1) Запустить backend (в другом проекте)

В проекте бэкенда (в соседнем окне) запустите:

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Важно: API должен быть доступен по адресу `http://127.0.0.1:8000`.

### 2) Запустить frontend (в ЭТОМ проекте)

Откройте терминал в корне этого репозитория и выполните:

```bash
cd frontend
npm install
npm run dev
```

После этого откройте в браузере:
- `http://localhost:5173`

## Где “живёт” `http://127.0.0.1:8000` (и куда его вписывать)

### Нормально: НИКУДА не вписывать

В dev-режиме фронтенд **по умолчанию** ходит на `http://127.0.0.1:8000`.
Это задано в коде здесь: `frontend/src/lib/api.ts` (функция `inferDefaultApiBase()`).

### Если всё-таки нужно указать другой адрес API (3 способа)

#### Способ A — самый простой (без файлов): через `?api=...`

Откройте web-интерфейс по ссылке вида:
- `http://localhost:5173/?api=http://127.0.0.1:8000`
- `https://<ВАШ_UI_NGROK>/?api=https://<ВАШ_API_NGROK>`

Это удобно для ngrok: просто меняете ссылку — и всё.

#### Способ B — через `.env.local` (удобно “закрепить”)

1) Создайте файл `frontend/.env.local`
2) Добавьте строку:

```bash
VITE_API_BASE=http://127.0.0.1:8000
```

3) Перезапустите `npm run dev`

#### Способ C — “в коде” (не рекомендуется)

Можно вручную изменить дефолт в `frontend/src/lib/api.ts`, но лучше используйте способы A или B.

## Ngrok (если нужно открыть доступ “снаружи”)

### Вариант 1: открыть наружу только backend

Если frontend у вас открыт локально (на ноуте), а наружу нужен только backend:
1) Поднимите ngrok для порта backend (`8000`)
2) Откройте UI так:

- `http://localhost:5173/?api=https://<ВАШ_API_NGROK>`

### Вариант 2: открыть наружу и frontend, и backend

1) Поднимите ngrok на порт frontend (`5173`) и backend (`8000`)
2) Откройте UI по ngrok-ссылке и добавьте `?api=...`:

- `https://<ВАШ_UI_NGROK>/?api=https://<ВАШ_API_NGROK>`

Примечание: в `frontend/vite.config.ts` уже добавлены разрешённые хосты для `.ngrok-free.dev`, чтобы dev-сервер Vite не ругался на ngrok-домен.

## Частые проблемы (быстро)

- **В браузере ошибки CORS**: это на стороне backend. В FastAPI нужно разрешить origin `http://localhost:5173` (и ваш UI ngrok-домен, если используете).
- **UI пишет “нет соединения”, но API вроде работает**: frontend проверяет `GET /` и ждёт ответ `{"status":"ok"}`. Если у вас на `/` другое — скажите разработчику бэкенда или пришлите сюда ответ `curl http://127.0.0.1:8000/`.

## Если нужен “статичный” запуск (без dev-сервера)

Это нужно реже. Но если хотите открыть уже собранный `dist`:

```bash
cd frontend
npm install
npm run build
npx serve -s dist -l 5173
```

Открывайте:
- `http://localhost:5173`
